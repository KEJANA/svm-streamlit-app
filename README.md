# 🧠 Disease Prediction using Support Vector Machine (SVM)

## 📌 Project Description
This project focuses on predicting disease outcomes using the Support Vector Machine (SVM) machine learning algorithm. SVM is a powerful supervised learning model that finds the optimal hyperplane to classify data points with maximum margin, ensuring high accuracy and robust performance.

The model is deployed as an interactive Streamlit web application that allows users to input medical parameters and obtain real-time prediction results.

---

## 🎯 Objective
The objective of this project is to build a reliable disease prediction system using the SVM algorithm, enabling accurate classification and assisting in early-stage health risk analysis.

---

## 🧠 Machine Learning Algorithm
- Support Vector Machine (SVM)
- Type: Supervised Learning (Classification)

SVM works by constructing an optimal decision boundary (hyperplane) that best separates different classes in the dataset, making it highly effective for complex and high-dimensional data.

---

## 📊 Dataset Information
The dataset includes important health-related features such as:

- Glucose Level
- Blood Pressure
- BMI
- Age
- Insulin Level
- Skin Thickness
- Pregnancies
- Diabetes Pedigree Function

Target Variable:
- Disease Outcome (Positive / Negative)
